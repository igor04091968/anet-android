# ANet 1.0.4: диагностика и подбор соединения

APK: `anet-1.0.4.apk`. Название приложения — ANet, пакет — `org.alco.anet.diagnostics`. Устанавливать поверх предыдущей диагностической версии, без удаления профилей. Рабочая стабильная версия остаётся отдельным приложением.

1. Выбрать импортированный профиль и группу серверов.
2. Остановить VPN, открыть «Диагностика» → «Быстрая».
3. После результата нажать «Подобрать настройки», выбрать кандидат, прочитать предлагаемые параметры.
4. Нажать «Применить и подключить».
5. Открыть сайт или ресурс с данными. После авторизации и приёма 64 КиБ приложение сохраняет подтверждённый вариант для этой сети.

Подбор изменяет временный порядок серверов, лимит внешних соединений и интервал попыток; исходный профиль сохраняется. При N=1 AHTTP исключается, поскольку ему нужны два соединения. Ключи, маршруты и шифрование остаются из профиля; MTU приходит от авторизованного сервера. Диагностические TLS-отпечатки не заменяют рабочий транспорт.

Подбор годен только для точного профиля, группы и физической сети, не более 30 минут. Смена сети требует нового подбора. Отмена или старый отчёт не применяются. Работающий VPN автоматически не перестраивается.

Откат: остановить VPN → «Диагностика» → «Исходные настройки» → подключиться снова.

Исходники Rust: `igor04091968/anet-vpn`, Android: `igor04091968/anet-android`, Android: ветка `feature/android-diagnostics-tuning-20261005`; Rust: ветка `feature/linux-diagnostics-tuning-20261006`. Сборка выполняется на внешнем USB. Нативные библиотеки, подпись APK, тесты и контрольная сумма проверяются перед публикацией. Поведение на физическом Galaxy A7 / Android 10 требуется проверить вручную. Это экспериментальный релиз; устойчивость к блокировкам не гарантируется.
